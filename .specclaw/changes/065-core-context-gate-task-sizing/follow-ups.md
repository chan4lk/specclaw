## Status at PR time

Every minor above except the last (round 10, `frontend`/`backend` Kinds in synth-agent) was fixed in a later
round. The loop was stopped at round 10 (the builder's cap was about eight). The final Opus pass still reported
four majors, none a blocker. All four are the same "malformed input falls back in silence" class, at a smaller
scope each round. They are open:

- [major B1] `lib/budget.py` `stated()`: tokenise the whole `specclaw budget:` line and refuse any token that is
  not `role=<role>` or `context=<digits>` (empty values, `role = x`, capitalised keys, unknown keys).
- [major B4] `lib/budget.py` `tasks()`: use the shared task-id rule `T[0-9][0-9.a-z]*` that
  `specclaw-update-task-status` uses, so a `- [ ] Tests pass` checklist line is not read as a task.
- [major B6] `lib/budget.py` `load()`: warn on an unknown key directly under `budget:` (`gates:`, `Gate:`, `role:`).
- [major B3] `lib/budget.py` `read_tokens()`: count 0 only for a path that does not exist; refuse or mark
  unsized a directory, a glob or a `path:10-40` entry.
