- draft-pr.sh: the push-failed record carries `bundle=saved|none`; exit code stays 4.
- Bundle base: the clone HEAD at the start of `prepare_workspace`, because `AGENT_HEAD` is taken after a resume and would drop earlier runs' commits, and `FLEET_COMMIT` is optional and may be older.
- ac41: saved (old pair replaced, no tmp left), none (no folder, read-only folder), resume, corrupt or non-ancestor ignored, remote branch wins, good push removes the pair.
