# T9 — Write the eval runner and the nightly workflow

`tests/run-infosec-evals.sh` reviews every case's `vulnerable` and `fixed` sample with the agent (`SPECCLAW_INFOSEC_REPS`
reps, default 3, neutral file names so the name never gives the answer away) and prints the catch rate, the
false-alarm rate and the model. It skips with exit 0 unless `SPECCLAW_INFOSEC_EVALS=1`, fails loudly when `claude` is
missing, and counts an empty answer as a miss, never as clear. `.github/workflows/infosec-evals.yml` runs it nightly
and on demand, skipping with a notice when the API key is absent. The structural suite now also checks the runner end
to end with a stub `claude` (skip path, catch and false-alarm scoring) and that the workflow exists.
