# T1 report

- **`lib/feature-graph.sh`:**
  - Members are the changes whose `proposal.md` (or lean `change.md`) carries `**Feature:** <module>`.
  - Dependencies come from `**Depends on:** a, b` (or `none`).
  - Waves are computed with Kahn's algorithm.
  - Errors name the changes involved: an unknown or foreign dependency, a cycle, a bad module name, or an empty feature.
- **`item_dir` (naming.sh):** resolves `changes/<x>`, then `features/<x>`. `work_item_id`, `proposal_approved`, `optin` and trigger's pushed-tree copy use it. `specclaw-azdo-issue`'s `CHANGE_DIR` falls back the same way.
- **`specclaw-fleet feature plan <module> [--json]`:** prints the waves and each member's dependencies.

**Tests:** `ac27_feature_graph.sh`, plus a features-dir row in `run-azdo-issue-optin-tests.sh`.
