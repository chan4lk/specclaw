# T6 — Bundle the mod into plugins/specclaw

Moved `hooks/{register.tsx,read.ts,refresh.ts,place.ts,core/}`, `types/index.d.ts`, `tsconfig.json`, `.gitignore` and the tests from `plugins/specclaw-mod` into `plugins/specclaw`, keeping the same relative layout so no import changed. `plugins/specclaw-mod` and its marketplace entry are gone.

- `hooks/hooks.json` now lists `"modules": ["./register.tsx"]` next to the SessionStart hook. `claude plugin validate` accepts the mix. The SessionStart command is now quoted, which validate requires.
- `plugin.json` gains `types` and `userConfig.gate`, with options `warn | block | off` and default `warn`. `register.tsx` falls back to `warn` too.
- The state key is now `specclaw.snapshot` (atom in `refresh.ts` and `PluginState` in `types/index.d.ts`).
- The hold tests in `place.test.ts` and `linked.test.ts` pin `gate: 'block'`. A new test checks that with no option set, the Write runs and a toast names `/specclaw:propose`.
- `run-plugin-split-tests.sh` AC-7 ("five plugins share one version") was failing on this branch before the move and passes now.

Not run: `tsc -p .`. The gitignored `.claude-plugin/types/` was lost in the move and I could not regenerate it (neither `plugin init` nor a `--plugin-dir` session writes it). `plugin validate` checks the state contract instead.
