- [minor B1] `plugins/specclaw-review/lib/review_core.py:203` Paths are decoded two different ways. `find_root` uses `errors="surrogateescape"` so that a path round-trips. `git()` uses `errors="replace"`, and it also returns paths (for example `diff --name-only -z`, or any output when `core.quotePath=false`). Not raised to major: with git's default `core.quotePath=true`, non-ASCII paths are octal-quoted, so no default-config scenario was shown. (round 5) <!-- fp:1264dbb00cac class:other -->
